# Stopwatch Web Application

## ⏱️ Project Overview
This project is a **Stopwatch Web Application** developed using **HTML, CSS, and JavaScript**.  
It allows users to **start, pause, reset**, and **record lap times**, making it easy to measure and track time intervals accurately.

The UI features a **simple and clean design** with **gradient-based circular elements**, ensuring a modern and user-friendly experience.

---

## 🚀 Features
- Start, Pause & Reset stopwatch
- Lap time recording
- Accurate time tracking (hours, minutes, seconds, milliseconds)
- Gradient-based circular UI design
- Responsive layout for all devices
- Smooth and interactive user experience

---

## 🛠️ Technologies Used
- **HTML** – Structure of the application  
- **CSS** – Styling, gradients & responsiveness  
- **JavaScript** – Stopwatch logic & interactivity
